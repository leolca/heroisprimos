## Conceitos STEM que Função representa

### 📈 **Funções como Linguagem Universal**

Uma **função** é uma regra que associa **cada entrada** a **exatamente uma saída**.

```
f: X → Y
x ↦ f(x)
```

**Domínio** (entradas válidas) → **Imagem** (saídas possíveis)

### 🎨 **Tipos de Funções no "Arsenal" da Função**

| Tipo | Forma | Aplicação no Quadrinho |
|------|-------|------------------------|
| **Linear** | f(x) = ax + b | Crescimento constante, taxa fixa |
| **Quadrática** | f(x) = ax² + bx + c | Trajetórias, otimização |
| **Exponencial** | f(x) = a·bˣ | Populações, juros, decaimento radioativo |
| **Logarítmica** | f(x) = logₐ(x) | Escalas (pH, Richter, dB), compressão |
| **Trigonométrica** | f(x) = A·sen(ωx + φ) | Ondas, oscilações, sinais |
| **Logística** | f(x) = L/(1+e^(-k(x-x₀))) | Crescimento limitado, epidemias |
| **Por partes** | Diferentes regras por intervalo | Sistemas reais com limiares |

### ⚡ **Cálculo: A Matemática da Mudança**

#### **Derivada** = Taxa de variação instantânea
```
f'(x) = lim(h→0) [f(x+h) - f(x)] / h
```
**No quadrinho**: Função "vê" a inclinação da tangente em cada ponto — **velocidade** de qualquer processo.

#### **Integral** = Acumulação / Área sob a curva
```
∫f(x)dx = F(x) + C  (indefinida)
∫ₐᵇ f(x)dx = F(b) - F(a)  (definida)
```
**No quadrinho**: Função "soma" infinitos pedacinhos — **distância total** da velocidade, **carga total** da corrente.

#### **Teorema Fundamental do Cálculo**
> **Derivação e Integração são operações inversas.**

```
d/dx [∫ₐˣ f(t)dt] = f(x)
∫ₐᵇ f'(x)dx = f(b) - f(a)
```

## Momentos Marcantes

### Edição #3: "A Epidemia Exponencial"
Um nanovírus se espalha: **N(t) = N₀·e^(rt)**.
Função lineariza no log: **ln(N) = ln(N₀) + rt** → reta!
Calcula **R₀**, **tempo de duplicação**, **limiar de imunidade coletiva** (1 - 1/R₀).

> *"Exponencial assusta. Mas log de exponencial é reta. Retas a gente domina."*

### Edição #6: "A Otimização Multidimensional"
Precisam alocar recursos limitados (energia, tempo, matéria-prima) para maximizar chance de sucesso.
**Programação linear** → **Método Simplex** → **Lagrange multipliers** para restrições.

## A Matemática por Trás dos Heróis

### 🎯 **Trabalho em Equipe = Composição de Funções**

```
Resultado final = Função ∘ Vetor ∘ Quark ∘ Pixel (entrada)
```

Cada herói **transforma** a entrada e passa para o próximo:
- **Pixel**: Decomposição algorítmica (entrada → subproblemas)
- **Vetor**: Modelagem física (subproblemas → equações diferenciais)
- **Quark**: Análise molecular/química (equações → parâmetros reais)
- **Função**: Otimização e síntese (parâmetros → solução ótima)

### 🔄 **Feedback Loops** (Laços de Retroação)

Sistemas reais têm **realimentação**:
```
Saída → Sensor → Comparador → Controlador → Entrada
```
Função projeta **controladores PID** (Proporcional-Integral-Derivativo) para estabilizar sistemas instáveis.
